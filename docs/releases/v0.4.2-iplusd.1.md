## Changes

- **Fixed view/movement direction drift after landing.** After swinging or rotating in the air, pushing the left stick forward follows the visible heading without needing to recenter. Confirmed in game by iplusd.
- **Added FOV smoothing.** Enable **FOV SLIDER**, then **FOV SMOOTHING** in **Settings → SPIDY VR**. Adjust the **SMOOTHING AMOUNT** directly underneath (25–500 ms); start at 150 ms. Higher values provide more smoothing with more camera delay.
- Smoothing affects only the desktop recording camera, follows all rotation axes, and does not lock the horizon or delay headset tracking. High-resolution timing prevents the filter from repeatedly resetting between frames.

## Installation

Extract **Spidy-0.4.2-win64.zip** into a new folder and run **Spidy Launcher.exe**. This is a complete package; no separate SpidyVR download is needed.

368 automated tests and the momentum rotation checks passed. The landing direction fix was also verified in game; recording performance can vary by system.
