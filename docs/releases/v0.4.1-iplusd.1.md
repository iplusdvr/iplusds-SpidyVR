# Changes

- Added an **OFF/ON** switch for the FOV slider in **Settings → SPIDY VR**.
- Turn **FOV SLIDER** on to adjust the **SPECTATOR FOV** value directly below it (40°–150°).
- Turn it off to restore the standard spectator view. Your selected FOV is saved for the next time you enable it.
- This setting only changes the desktop and recording view; headset FOV is unchanged.

This is a complete package. Extract the ZIP into a new folder and start **Spidy Launcher.exe**.

Based on SpidyVR by Ilya Mezerowsky, with FOV, near clip and realistic swinging additions by iplusd. Movement inspired by Blaze's Spider-Man mod for Blade & Sorcery.
